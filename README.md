Library Management System

A simple console-based Library Management System in C++ built with structures, file handling, and permanent storage.

This project allows the user to manage books and members using a text-based menu interface.

Features
Add new books
Add new Accounts
Show all available books
Issue a book to a member
Return a book
Permanent storage using file handling
Automatic data loading on startup
Technologies Used
C++
Structures (struct)
Functions
Arrays
File Handling (fstream)
File Storage

The program stores data permanently in:

books.txt → stores all book records
accounts.txt → stores all member records

This ensures data remains saved even after closing the program.
